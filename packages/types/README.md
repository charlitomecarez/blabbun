# @openblobs/types

Shared TypeScript types used across all openblobs apps and packages.

## Usage

```ts
import type { Post } from "@openblobs/types";
```

## Navigation

| Command          | Description           |
| ---------------- | --------------------- |
| `pnpm cd:root`   | Jump to monorepo root |
| `pnpm cd:client` | Jump to `apps/client` |
| `pnpm cd:admin`  | Jump to `apps/admin`  |
| `pnpm cd:ui`     | Jump to `packages/ui` |
